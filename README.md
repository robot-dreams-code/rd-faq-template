# r_d FAQ — шаблон

Інтерактивна сторінка FAQ у стилі robot_dreams. Питання й налаштування беруться з Google Sheets,
сторінка хоститься на GitHub Pages. Один шаблон — окремий репозиторій і окрема таблиця для кожного курсу.

## Новий курс за 5 хвилин

1. **Таблиця.** Створіть Google-таблицю з двома вкладками: `faq` і `settings`.
   Найшвидше — імпортувати приклади: Файл → Імпорт → `data/faq.csv` (вставити як новий аркуш), потім так само `data/settings.csv`. Назвіть вкладки `faq` і `settings`.
2. **Доступ.** Налаштування доступу → «Усі, хто має посилання» → «Читач».
3. **Репозиторій.** На GitHub: «Use this template» → новий репозиторій (наприклад, `faq-product-manager-pro`).
4. **Конфіг.** У `config.js` вставте `sheetId` — частину адреси таблиці між `/d/` і `/edit`.
5. **Публікація.** Settings → Pages → Deploy from a branch → `main` / root.
6. **Резервна копія.** Actions → Sync FAQ snapshot → Run workflow (далі запускається щогодини сам).

Після цього контент редагується лише в таблиці. Зміни з'являються на сайті протягом кількох хвилин.

## Вкладка `faq`

| id | category | question | answer | order | active |
|---|---|---|---|---|---|
| format | Навчання | Як проходить навчання? | Текст відповіді… | 1 | TRUE |

- **id** — якір для посилання: `…/faq/#format`. Латиницею, без пробілів. Якщо порожньо, згенерується з питання, але тоді посилання зміниться, коли зміниться текст питання.
- **category** — розділ. Порядок розділів = порядок їхньої першої появи в таблиці.
- **order** — порядок усередині розділу.
- **active** — `FALSE` ховає питання з сайту. Порожньо = показувати.
- Назви колонок можна писати й українською: `категорія`, `питання`, `відповідь`, `порядок`, `показувати`.

У відповідях працює Markdown: `**жирний**`, `[посилання](https://…)`, списки через `- ` або `1. `, переноси рядків (Alt+Enter у клітинці). HTML-теги очищаються з міркувань безпеки.

## Вкладка `settings`

| key | value |
|---|---|
| course_name | Назва курсу — великий заголовок |
| course_subtitle | Підзаголовок |
| subbrand | Підпис у плашці біля логотипа (`faq`, `start`…) |
| tags | Плашки над заголовком через кому: `онлайн-курс, 4 місяці` |
| accent | Акцентний колір курсу, HEX: `#4BD86A` |
| site_url, site_label | Посилання в шапці |
| contact_title, contact_text, contact_label, contact_url | Блок «Не знайшли відповідь?». Без `contact_url` блок не показується |

Колір тексту на акцентних плашках (чорний чи білий) підбирається автоматично за контрастом.

## Брендові файли

- **Шрифт.** Vin Mono Pro — платний: покладіть `VinMonoPro-Bold.woff2` у `assets/fonts/`. До того часу працює JetBrains Mono.
- **Логотип.** За замовчуванням плашка `r_d` малюється CSS. Для офіційного SVG покладіть файл у `assets/` і вкажіть шлях у `config.js → logoSrc`.

## Як працює завантаження

Сторінка читає таблицю напряму через `docs.google.com/.../gviz/tq?tqx=out:csv`. Якщо таблиця недоступна, показується копія з `data/*.csv`, яку щогодини оновлює GitHub Action, і внизу з'являється позначка «Показано збережену копію відповідей».

`config.js → source: "snapshot"` вмикає режим, коли сторінка взагалі не звертається до Google і читає лише `data/`.

## Якщо не працює

- **Сторінка показує копію, а не свіжі дані / Action падає з «HTML замість CSV».** Таблиця не відкрита за посиланням. У корпоративному Google Workspace адмін може забороняти доступ поза доменом — перевірте посилання в режимі інкогніто. Варіанти: попросити виняток для цієї таблиці або використати «Опублікувати в інтернеті» і вставити CSV-посилання в `faqCsvUrl` / `settingsCsvUrl`.
- **Не видно питання.** Перевірте, що заповнена колонка `question` і `active` не дорівнює `FALSE`.
- **Розділ не в тому місці.** Перемістіть перший рядок цього розділу вище в таблиці.
- **Розклад Action зупинився.** GitHub вимикає розклад у неактивних репозиторіях; запустіть вручну в Actions.

## Структура

```
index.html            сторінка
config.js             налаштування курсу (sheetId)
assets/style.css      стилі за стайлгайдом
assets/app.js         завантаження, пошук, категорії, посилання
assets/vendor/        marked 12.0.2 (MIT), DOMPurify 3.1.6 (Apache-2.0/MPL-2.0)
assets/fonts/         Vin Mono Pro (додати)
data/                 резервна копія таблиці + приклад для імпорту
scripts/sync.mjs      синхронізація таблиці в data/
.github/workflows/    розклад синхронізації
```
